# Easy Story Wording Plan v0.1.3

The current v0.1.2 story logic is acceptable, but the wording is too technical. The next story-only update should keep the same strong supply/demand OB logic and change only the text shown in the panel.

| Current wording | Easier wording |
|---|---|
| Final | Big Picture |
| Key Source | Main Level Source |

| 1H Role | 1H Meaning |
