# v1.2.3 Manual Anchor Calibration Guide

## Purpose

v1.2.3 is a calibration version.

It is not meant to prove the auto KL engine is already correct. It is meant to compare the automatic KL engine against Ravi's manual NCI anchors.

Permanent rule:

```text
Manual NCI anchor beats automatic KL until auto engine proves alignment.
```

## Correct Pine file

```text
05_PINE/01_VERSIONS/nci_smc_market_story_visualizer_v1_2_3_manual_anchor_calibration.pine
```

## How to use it

### Step 1 — Pick one clear chart

Start with one higher timeframe where Ravi can clearly identify the structure.

Recommended:

```text
BTCUSD 4H
BTCUSD 1H
XAUUSD 4H
XAUUSD 1H
```

Avoid starting on 1M or 5M because lower timeframes are only child/explanation layers.

### Step 2 — Identify manual NCI anchors

From Ravi's manual drawing, identify:

```text
Manual KL UP
Manual KL DOWN
Manual Direction
```

Use the active parent story, not every visible historical level.

### Step 3 — Enter settings

In TradingView indicator settings:

```text
Enable Manual Anchor Calibration = ON
Manual Anchor TF = H4 / H1 / M15 / M5
Manual Direction = Bullish / Bearish / Range / Mixed
Manual KL UP = Ravi's manual KL UP price
Manual KL DOWN = Ravi's manual KL DOWN price
Manual Anchor Overrides Auto Story = ON
```

### Step 4 — Read panel

Focus on these rows:

```text
Manual
Auto
Compare
```

The Compare row can show:

```text
aligned
auto too high
auto too low
auto missing
direction mismatch
```

### Step 5 — Screenshot rules

Send screenshot when:

```text
Auto KL UP is too high or too low
Auto KL DOWN is too high or too low
Auto KL is missing
Auto direction disagrees with manual direction
Manual lines do not display correctly
```

## What not to judge yet

Do not judge the final trading story yet.

v1.2.3 is not about trade entries. It is not about SMC/SATS yet. It is about calibrating automatic KL detection against manual NCI truth.

## Calibration examples

### If panel says auto too high

Meaning:

```text
The auto engine chose a structure point above Ravi's manual KL.
```

Likely fix in v1.2.4:

```text
Auto engine needs to select the earlier/lower valid structure leg or parent anchor.
```

### If panel says auto too low

Meaning:

```text
The auto engine chose a structure point below Ravi's manual KL.
```

Likely fix in v1.2.4:

```text
Auto engine may be selecting obsolete structure or wrong swing depth.
```

### If panel says auto missing

Meaning:

```text
Auto engine failed to confirm a KL where Ravi sees a valid NCI KL.
```

Likely fix in v1.2.4:

```text
Auto engine is too strict or missing pullback/range validation logic.
```

### If panel says direction mismatch

Meaning:

```text
Auto engine's cycle state disagrees with Ravi's manual market story.
```

Likely fix in v1.2.4:

```text
Auto engine needs parent cycle memory and breakout/pullback validation.
```
