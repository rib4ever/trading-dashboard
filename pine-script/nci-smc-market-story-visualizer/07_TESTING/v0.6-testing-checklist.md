# v0.6 Testing Checklist

Use this checklist only when Ravi is asked to test v0.6 or later.

## When to test

Do not test every internal build.

Test when:

```text
1. A Pine version introduces a major visual/logic layer.
2. A compile issue is suspected.
3. A screenshot is needed to validate story readability.
4. The assistant explicitly says: test this version now.
```

## Latest version to test when requested

```text
05_PINE/01_VERSIONS/nci_smc_market_story_visualizer_v0_6_fractal_child_structure_engine.pine
```

## Basic compile test

Check only:

```text
1. Script compiles in TradingView.
2. Panel appears in Mobile Compact mode.
3. Text is readable on Ravi's white chart background.
4. No giant labels block the chart.
```

## Functional story test

Use these charts:

```text
BTCUSD 5M
BTCUSD 30M
XAUUSD 5M
XAUUSD 30M
```

Check only these story items:

```text
1. The panel shows 4H master story.
2. The panel shows 4H anchor.
3. 1H explains 4H.
4. 15M explains 1H.
5. 5M explains 15M.
6. If 4H creates LL/HH, LTF reaction is described as pullback explanation first.
```

## Do not judge yet

Do not judge final NCI accuracy yet because these are still not fully implemented:

```text
valid NCI breakout
valid NCI pullback
range engine
supply/demand engine
SMC liquidity context
final story decision engine
```

## What screenshots should show

When testing, send screenshots only if:

```text
panel is unreadable
chart is too messy
wrong timeframe role appears
LL/HH reaction rule appears clearly wrong
script does not compile
```
