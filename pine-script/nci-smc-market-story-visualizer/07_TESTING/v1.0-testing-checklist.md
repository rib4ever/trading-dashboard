# v1.0 Testing Checklist

v1.0 is the first version Ravi should test as a complete visual story base.

## Latest version

```text
05_PINE/01_VERSIONS/nci_smc_market_story_visualizer_v1_0_integrated_story_base.pine
```

## Test purpose

Do not judge final trading accuracy yet.

The goal is to check whether the full story framework is readable and directionally correct.

## Basic compile / mobile test

Check:

```text
1. Script compiles in TradingView.
2. Mobile Compact panel is readable.
3. Black font is readable on white chart background.
4. Final Story label does not block too much of the chart.
5. Chart is not too messy with KL + range + SD boxes.
```

## Recommended charts

Test only these first:

```text
BTCUSD 5M
BTCUSD 30M
XAUUSD 5M
XAUUSD 30M
```

## What to check in the panel

Look for these rows:

```text
Final
Confidence
4H
1H
Range/SD
NCI
```

The story should read like a connected narrative, not independent signals.

## Special scenario to watch

If 4H is bearish and price reacts upward from a 4H LL, panel should say something similar to:

```text
4H bearish continuation; 1H explains pullback from 4H LL
```

If 4H is bullish and price reacts downward from a 4H HH, panel should say something similar to:

```text
4H bullish continuation; 1H explains pullback from 4H HH
```
