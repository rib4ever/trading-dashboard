# v1.2 Ravi Lower-Timeframe Readability Feedback

Date: 2026-05-10

## Tested file

```text
05_PINE/01_VERSIONS/nci_smc_market_story_visualizer_v1_2_real_nci_structure_engine.pine
```

## Ravi's observation

Ravi confirmed that v1.2 compiles and the panel is mobile-friendly, but lower timeframes become harder to read.

Summary of user feedback:

```text
On higher timeframes, the key levels make some sense.
The lower I go, the more complicated it gets.
It does not fully make sense to me visually.
I see key levels, visuals, and panel, but I am not sure how to read the story.
```

## Interpretation

This feedback is valid and important.

v1.2 is currently showing multiple layers at the same time:

```text
chart timeframe range/KL
master 4H KL
supply/demand candidate boxes
range midline
story panel
manual chart drawings already present on Ravi's chart
```

On lower timeframes, this creates visual noise because the script is not yet applying enough story-based visual filtering.

## Core issue

The lower timeframe should not show all candidate structures equally.

It should show only the elements that explain the active parent story.

## Required next patch

v1.2.1 / v1.3 should introduce a Story-Filtered Visual Mode.

Required changes:

```text
1. Add Visual Detail Mode:
   - Ultra Clean
   - Story
   - Debug

2. Default mobile mode should be Ultra Clean.

3. In Ultra Clean mode, show only:
   - active parent KL being explained
   - current chart TF working KL
   - one active decision zone
   - story panel

4. Hide or fade:
   - inactive SD boxes
   - old candidate zones
   - range midline when not useful
   - master KL labels if too far away or not active

5. Panel must explain what the visible levels mean:
   - Parent level being tested
   - Child mission
   - Recalc status
   - What to watch next

6. Add role-based labels:
   - Parent KL
   - Working KL
   - Decision Zone
   - Rebuild/Retest Level
```

## Reading rule to preserve

The visualizer should not ask Ravi to read every line manually.

The panel must tell the story first, and the chart must only support that story.

```text
Panel = story brain
Chart visuals = only the evidence needed for that story
Debug mode = all candidates
```

## Next development priority

Before adding more SMC/SATS logic, improve lower-timeframe readability and visual filtering.

Suggested next patch:

```text
v1.2.1 Story-Filtered Visual Cleanup
```

Goal:

```text
make lower timeframe visuals easier to read before expanding the engine further
```
