# v1.2.2.1 Visibility and Far Parent KL Feedback

Date: 2026-05-10

## Ravi's feedback

Ravi tested v1.2.2.1 on XAUUSD / Gold and reported:

```text
What is this?
When I get back from 1M to 5M, the indicator goes invisible, but no errors.
```

## Screenshot observation

The indicator compiled and displayed the panel, but the visible chart became confusing because the parent KL levels were very far away from current price.

Observed levels:

```text
Parent KL DOWN around 4764.710
Parent KL UP around 4672.740
Current price around 4713.560
```

This caused the chart to scale to very wide parent levels, while useful lower-timeframe working KLs were not visible because the working structure was not confirmed.

## Root cause

v1.2.2.1 became too strict and too parent-KL focused:

```text
1. It suppresses working KL when working structure is not confirmed.
2. It still draws far-away parent KLs.
3. Far-away parent KLs expand the chart scale.
4. Lower timeframe may look empty/invisible because there is no confirmed working KL to draw.
```

## Important interpretation

This is not a TradingView runtime error.

The indicator is not truly broken; it is visually unhelpful in this state.

The chart says:

```text
Parent clear, child KL not confirmed yet.
```

But visually it draws parent KLs that are too far away to be useful for scalping/chart reading.

## Required next patch

Create v1.2.2.2 Visibility + Local Context Guard.

Required changes:

```text
1. Add Max Parent KL Distance ATR setting.
2. Hide or fade parent KL if too far from current price.
3. Add Local Context fallback when no working KL is confirmed.
4. If working KL is not confirmed, show candidate edges only as Candidate Edge, not KL.
5. Add panel row: Visible Mode / Reason.
6. Add state: Parent far away; showing local candidate context.
7. Avoid stretching the chart scale with far-away parent lines by default.
```

## Updated visual rule

```text
Parent KL is part of the story, but it should not destroy lower-timeframe readability.
```

## Correct visual behavior should be

If parent KL is too far:

```text
Panel: Parent clear but far from current price; local context shown.
Chart: Hide/fade parent KL, show local candidate edge or local working KL if confirmed.
```

If working KL is not confirmed:

```text
Panel: Child KL not confirmed yet.
Chart: show candidate edge only if enabled or if local fallback mode is on.
```

## Next build priority

```text
v1.2.2.2 Visibility + Local Context Guard
```

This patch should happen before further KL accuracy improvements, because Ravi needs the indicator to remain readable while the logic is refined.
