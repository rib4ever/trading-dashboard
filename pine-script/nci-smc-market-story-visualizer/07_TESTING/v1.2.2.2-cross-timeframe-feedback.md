## Remaining major issue

The indicator is still not reading structure like Ravi's manual NCI drawings.

Examples from screenshots:

```text
Manual H4/H1 KL zones are drawn by Ravi around clear swing/impulse structure.
The script still sometimes says No confirmed parent KL yet.
On lower TFs it shows local edge high/low, but those edges are not yet true NCI story levels.
```

## Key interpretation

The visibility problem is improved, but the structure intelligence is still incomplete.

The current engine still depends too much on latest swing pairs and does not preserve a connected NCI wave path across higher timeframes.

## Required next phase

Next build should be v1.2.3 Manual-Anchor Calibration Mode.

Purpose:

```text
Allow Ravi to calibrate the engine against his manual drawings.
```

## v1.2.3 required features

```text
1. Add Manual Anchor Mode setting.
2. Add optional manual HTF KL UP and HTF KL DOWN inputs.
3. Add optional manual active structure direction input.
4. Add manual anchor labels separate from auto KL labels.
5. Panel compares Auto vs Manual:
   - Auto parent direction
   - Manual parent direction
   - Auto KL distance from manual KL
   - Auto status: aligned / too high / too low / missing
6. Auto KL should not pretend confidence if manual anchor disagrees.
7. Use manual anchor as temporary truth source for calibration.
```

## Why this is necessary

Without manual-anchor calibration, the project will keep guessing KL logic from screenshots.

Ravi already has the correct visual NCI structure in his manual drawings. The indicator should first learn to align with those manual anchors before expanding SMC/SATS.

## Next development priority

```text
v1.2.3 Manual-Anchor Calibration Mode
```

After v1.2.3, Ravi can enter his manually identified H4/H1 KL UP/DOWN levels and compare script output against his drawings.

This will make refinement faster and more objective.

## Permanent project law

```text
Manual NCI anchor beats automatic KL until auto engine proves alignment.
```
