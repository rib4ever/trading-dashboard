## Example

```text
Date: 2026-05-10
Symbol: BTCUSD
Chart timeframe: 1H
Manual Anchor TF: H4
Manual Direction: Bullish
Manual KL UP: 74200
Manual KL DOWN: 81200
Auto Direction / Cycle: Transition / mixed
Auto KL UP: n/a
Auto KL DOWN: n/a
Compare UP: auto missing
Compare DOWN: auto missing
Direction Compare: direction mismatch
Screenshot reference: Ravi manual H4/H1 screenshot
Ravi comment: Manual H4 story is bullish, but auto still says no confirmed parent KL.
```

## How this log helps v1.2.4

Each record identifies exactly what needs to change in the auto KL engine:

```text
auto missing = auto rules too strict or missing NCI leg validation
auto too high = wrong upper anchor / wrong structure leg
auto too low = obsolete or wrong lower anchor
direction mismatch = market-cycle state engine wrong
```
