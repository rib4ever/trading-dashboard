## Key lesson

The script must not treat the current state as a random bullish/bearish continuation only.

The correct NCI story should be hierarchy-based:

```text
4H parent level touched / reacted
1H explains the pullback from the 4H reaction
15M explains the internal structure of the 1H pullback
5M explains execution/local reaction only
```

## Current v1.2.3.1 limitation

v1.2.3.1 can manually anchor one TF at a time, but Ravi is already thinking in a multi-anchor stack.

The current manual input model is too limited because it only accepts one manual anchor pair:

```text
Manual Anchor TF
Manual KL UP
Manual KL DOWN
Manual Direction
```

But Ravi's actual workflow needs simultaneous anchors:

```text
Manual 4H KL UP / KL DOWN
Manual 1H KL UP / KL DOWN
Manual 15M KL UP / KL DOWN
Manual 5M KL UP / KL DOWN
```

## Important story rule from this test

```text
When price touches 4H KL DOWN and starts pulling back, lower TF bullish structure may only be a pullback explanation, not a full 4H bullish reversal.
```

## Next project law

```text
A lower timeframe structure must be interpreted through the active parent event.
```

If the active parent event is 4H KL DOWN reaction, then 1H/15M/5M are explaining the pullback or confirming a true parent break, not creating an independent story.
