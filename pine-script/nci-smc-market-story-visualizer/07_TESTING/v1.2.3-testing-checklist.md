# v1.2.3 Testing Checklist

## Correct file to test

```text
05_PINE/01_VERSIONS/nci_smc_market_story_visualizer_v1_2_3_manual_anchor_calibration.pine
```

## Purpose

v1.2.3 is not mainly about improving automatic KL immediately. It is a calibration tool so Ravi can compare the automatic KL engine against his manual NCI anchors.

## First test

Check only:

```text
1. Does it compile?
2. Does the panel show v1.2.3?
3. Do manual-anchor settings appear?
4. Can manual KL UP / KL DOWN be entered?
5. Do manual aqua/fuchsia lines appear?
6. Does the Compare row show aligned / auto too high / auto too low / auto missing?
```

## Suggested first calibration

Use one clear chart where Ravi already knows the manual levels:

```text
BTCUSD 4H or 1H
or
XAUUSD 4H or 1H
```

Enter:

```text
Manual Direction
Manual KL UP
Manual KL DOWN
```

Then review panel:

```text
Manual
Auto
Compare
```

## What screenshots to send

Send screenshots when:

```text
Auto KL is too high
Auto KL is too low
Auto KL is missing
Auto direction disagrees with manual direction
Manual lines do not display correctly
```

## Do not judge yet

Manual mode is for calibration. It is expected that auto may disagree.

The disagreement is useful because it tells us exactly how to improve v1.2.4.
