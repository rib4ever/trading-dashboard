## Test goal

v1.3.2 is a safety/correctness patch.

It should stop showing random pivot levels as confirmed KLs.

## Expected behavior

If the engine cannot validate a true NCI KL, it should say:

```text
Candidate only; no confirmed KL
```

And chart labels should say:

```text
CANDIDATE 1H HIGH - not KL
CANDIDATE 1H LOW - not KL
```

not:

```text
AUTO KL UP
AUTO KL DOWN
```

## First checks

```text
1. Does it compile?
2. Does panel show v1.3.2?
3. Does it avoid calling weak/random levels KL?
4. Does the panel explain why no KL is confirmed?
5. If confirmed KL appears, does it make more sense than v1.3.1?
```
