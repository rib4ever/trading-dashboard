## Goal

This is the first clean refactor using:

```text
SMC-style swing architecture as reference
NCI rules as logic authority
```

## What changed from v1.3.x

```text
1. No random pivot promotion into KL.
2. Candidate highs/lows are clearly labelled candidate/not KL.
3. Confirmed KL requires NCI breakout validation.
4. Dashboard tells a 4H -> 1H -> 15M -> 5M story.
5. Lower TF is treated as explanation of parent, not independent random story.
```

## First test

Paste the script into TradingView and check:

```text
1. Does it compile?
2. Does panel show v1.4.0 alpha?
3. Are candidate levels labelled as candidate/not KL?
4. Are confirmed KLs fewer and more logical?
5. On BTCUSD 15M / 1H, does the 4H story make more sense than v1.3.1?
```

## Important expected behavior
