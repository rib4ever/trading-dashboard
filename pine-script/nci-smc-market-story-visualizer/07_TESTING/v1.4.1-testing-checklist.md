## Purpose

This version directly responds to Ravi's v1.4.0 alpha screenshot feedback.

## What changed

```text
1. Mitigated / broken candidates should no longer remain active.
2. Candidate search scans backward for the next unmitigated candidate.
3. Confirmed KL and candidates are shown as rectangular zones, not only lines.
4. Labels are pushed to the right with different offsets by timeframe.
5. The 4H confirmed KL direction remains the main anchor of the story.
```

## Important note

This is still an alpha. The mitigation filter is simple first-pass logic:

```text
High candidate obsolete if close > candidate high + ATR buffer
Low candidate obsolete if close < candidate low - ATR buffer
```

Later versions should add stricter NCI retest / mitigation logic.
