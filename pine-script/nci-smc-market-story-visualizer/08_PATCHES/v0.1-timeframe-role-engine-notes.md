# v0.1 Timeframe Role Engine Notes

Branch: `nci-story-v0.1`

## Purpose

This patch starts the first real Pine development layer after the blueprint.

It creates a new version file:

```text
05_PINE/01_VERSIONS/nci_smc_market_story_visualizer_v0_1_timeframe_role_engine.pine
```

## What v0.1 adds

- Configurable 4-timeframe stack.
- Default hierarchy: 4H → 1H → 15M → 5M.
- Current chart timeframe role detection.
- Current chart timeframe working layer status.
- Story panel expanded to show hierarchy and temporary alignment.
- Temporary EMA-based context gauge for display only.
- No trading signals.
- No final NCI structure logic yet.

## Important limitation

The bullish/bearish context shown in v0.1 is **temporary** and based on an EMA gauge only.

It is not the final NCI market-structure engine.

Future versions will replace this with connected NCI logic:

```text
4H master structure
→ 4H event anchor
→ 1H explanation
→ 15M explanation
→ 5M reaction
```

## Why this matters

Before building NCI structure, the script must first understand the user's selected timeframe hierarchy and the current chart timeframe.

This version confirms the story stack can be displayed and reasoned about cleanly.
