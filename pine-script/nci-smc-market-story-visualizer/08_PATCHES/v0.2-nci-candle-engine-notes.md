## What v0.2 adds

- Maru / Marubozu detection.
- Special Maru detection.
- Pinbar detection.
- Doji detection.
- Normal candle classification.
- Current chart candle story in the panel.
- Selected stack candle snapshots.
- Optional candle markers.
- Debug ratios for body, upper wick, lower wick.

## NCI principle preserved

Candles are not meant to be read one by one everywhere.

The Candle Engine prepares classification, but the final Story Engine should mainly use it at:

```text
key levels
range edges
pullback areas
breakout lines
event anchors
supply/demand zones
```

## Initial classification logic

### Maru

```text
body / total range >= 70% by default
```

### Special Maru

Bullish:

```text
bull candle
body / range >= 50%
long lower wick
close near high
```

Bearish:

```text
bear candle
body / range >= 50%
long upper wick
close near low
```

### Pinbar

```text
body / range <= 50%
dominant wick >= 55% of range
```

### Doji

```text
body / range <= 15%
small candle based on ATR filter
```

### Normal

Anything not classified above.
