## Important limitation

This is still **preliminary** KL detection.

It uses pivot highs/lows as the first key-level foundation, but it is not yet the final NCI connected market-structure logic.

Final KL logic must come from the active connected 4H story:

```text

→ pulse
→ pullback
→ valid breakout
→ range if formed
→ current story-relevant KLs
```
