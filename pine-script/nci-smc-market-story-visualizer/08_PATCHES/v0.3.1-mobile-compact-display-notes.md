# v0.3.1 Mobile Compact Display Patch Notes

Branch: `nci-story-v0.3.1-mobile`

## Purpose

This patch improves usability on mobile devices.

After Ravi tested v0.3 on TradingView mobile, the story panel was too large and covered the chart.

v0.3.1 keeps the v0.3 foundation but adds a mobile-friendly display system.

## New file

```text
05_PINE/01_VERSIONS/nci_smc_market_story_visualizer_v0_3_1_mobile_compact_patch.pine
```

## What v0.3.1 adds

- Mobile Compact panel mode.
- Normal panel mode.
- Full Debug panel mode.
- Panel position selector:
  - Top Right
  - Top Left
  - Bottom Right
  - Bottom Left
- Tiny text size in Mobile Compact mode.
- Big chart role label disabled by default.
- Shorter KL labels.
- Shorter story text.
- Still keeps chart KL lines and current chart TF working layer.

## Mobile Compact panel shows only

```text
Stack: 4H → 1H → 15M → 5M
Chart TF role
Chart KL UP / DOWN
Current candle type
Current preliminary KL state
Next engine
```

## Core mind preserved

This patch does not change the core logic.

It still follows:

```text
4H = master story
1H explains 4H
15M explains 1H
5M explains 15M
current chart TF = working layer
NCI = structure backbone
SMC = support context
```

## Important limitation

This is still preliminary KL + candle + timeframe-role logic.

The next major build remains:

```text
v0.4 — 4H Master Structure Engine
```

v0.4 should begin connected 4H structure path logic and avoid random trend marking.
