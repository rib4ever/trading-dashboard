# v0.3.2 Light Theme / Black Font Notes

Branch: `nci-story-v0.3.2-theme-base`

## Purpose

Ravi tested v0.3.1 on TradingView mobile with a white/light chart background.

The mobile compact panel works well, but the text should use black fonts for readability on a light chart.

## Requested design direction

- Keep mobile compact layout.
- Use black fonts by default for the current light-background workflow.
- Add a basic theme foundation now.
- A richer theme engine can be added later, similar to previous Pine projects.

## Theme direction

For now:

```text
Default theme = Light Chart
Text color = black
Panel background = light transparent
Header background = light gray
KL UP = green
KL DOWN = red
```

Future:

```text
Light Theme
Dark Theme
High Contrast Theme
Custom Theme
```
