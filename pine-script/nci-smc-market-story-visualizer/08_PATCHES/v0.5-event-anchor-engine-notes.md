## Important core scenario handled

When 4H is bearish and creates a new lower low, the 1H move from that 4H LL is **not treated as a trend reversal by default**.

It is handled as:

```text
4H bearish continuation candidate
→ price reaches / reacts from new 4H LL
→ 1H mission = explain pullback from new 4H LL
→ wait to see if 1H pullback forms LH / KL DOWN rejection
→ bearish continuation remains active until valid 4H reversal or valid 4H breakout against bearish structure
```

So the script should not blindly flip bullish just because 1H rises from the 4H LL.

## Logic rule

```text
LTF reaction from HTF LL/HH = pullback explanation first.
HTF continuation story remains active until HTF structure is invalidated.
```
