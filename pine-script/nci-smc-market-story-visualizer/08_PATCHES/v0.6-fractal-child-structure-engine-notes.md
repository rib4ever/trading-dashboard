# v0.6 Fractal Child Structure Engine Notes

Branch: `nci-story-v0.6-child-engine`

## Purpose

This patch starts the fractal child-structure explanation layer.

The indicator must not read lower timeframes randomly. Each child timeframe must explain the parent timeframe event anchor.

```text
4H anchor → 1H explanation
1H anchor → 15M explanation
15M anchor → 5M explanation
```

## What v0.6 adds

- Child mission scoring for 1H, 15M, and 5M.
- Parent/child relationship text.
- Differentiates:
  - continuation support,
  - pullback explanation,
  - transition warning,
  - range/unclear explanation.
- Preserves the HTF LL/HH reaction law.
- Keeps mobile compact panel and light theme black font.

## Mandatory rule preserved

```text
LTF reaction from HTF LL/HH = pullback explanation first.
HTF continuation story remains active until HTF structure is invalidated by valid NCI structure rules.
LTF movement can warn, clarify, or explain, but it cannot override the HTF story alone.
```

## Important limitation

This is still not full NCI validation.

The child explanation engine currently uses preliminary structure context and relation states. Future versions must add:

```text
valid pullback standard
valid breakout standard
range story engine
SMC liquidity context
NCI SD zone integration
```
