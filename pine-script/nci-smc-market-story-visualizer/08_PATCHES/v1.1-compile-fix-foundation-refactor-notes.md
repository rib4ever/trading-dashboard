# v1.1 Compile Fix + Foundation Refactor Notes

Branch: `nci-story-v1.1-compile-fix`

## Purpose

This patch fixes the TradingView compile issues found by Ravi when testing v1.0 on mobile.

v1.0 was the first integrated story base, but TradingView exposed Pine syntax/type issues that needed to be corrected before visual testing can continue.

## Issues fixed

### 1. Short title too long

TradingView requires `shorttitle` to be 10 characters or less.

Fixed by shortening the indicator shorttitle to:

```text
NCIStory
```

### 2. Reserved variable name `range`

Pine cannot use `range` as a variable/function name.

Fixed by renaming the final-story local variable to:

```text
rangeCtx
```

### 3. `ta.valuewhen()` returning strings

Pine does not allow `ta.valuewhen()` with a string source.

Fixed by replacing string-returning SD type functions with numeric code functions:

```text
1 = normal candidate
2 = strongest candidate
```

Then the numeric code is converted into readable text later.

### 4. SD type handling refactor

Demand/supply type logic is now separated:

```text
f_lastDemandCode()
f_lastSupplyCode()
f_demandTypeText()
f_supplyTypeText()
```
