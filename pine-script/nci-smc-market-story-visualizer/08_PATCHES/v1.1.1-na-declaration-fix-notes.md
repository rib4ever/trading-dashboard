# v1.1.1 NA Declaration Fix Notes

Branch: `nci-story-v1.1.1-na-declaration-fix`

## Purpose

Ravi tested v1.1 and found one remaining TradingView compile issue around line/label/box declarations.

TradingView error:

```text
Value with NA type cannot be assigned to a variable that was defined without type keyword
```

## Root cause

This syntax can confuse Pine's type inference when multiple variables are declared on one line:

```pine
var line cUp = na, cDn = na, rMid = na
```

Pine accepts the explicit type only for the first variable clearly, while the later variables may be treated as untyped `na`.

## Fix

All line, label, and box variables are now declared separately with explicit types:

```pine
var line cUp = na
var line cDn = na
var line rMid = na
var label cUpL = na
var box dBox = na
```
