# v1.2 Real NCI Market Structure Engine Notes

Branch: `nci-story-v1.2-real-structure-engine`

## Purpose

v1.2 moves the project from a working visual foundation toward the real NCI market-structure brain.

v1.1.1 confirmed that the indicator compiles and displays correctly on TradingView mobile. v1.2 begins building the logic that makes the story adapt when a parent timeframe structure is broken.

## Core focus

The main purpose of v1.2 is to introduce a parent-child hierarchy state engine.

```text
4H → 1H
1H → 15M
15M → 5M
```

Each parent timeframe controls the child timeframe below it.

## New structure states to introduce

```text
Parent continuation active
Parent pullback active
Parent reaction active
Parent break attempt
Parent valid break
Parent transition
Parent rebuild mode
Child explanation mode
Child warning mode
Child recalculation mode
Broken-level retest mode
```

## Mandatory rules preserved

```text
LTF reaction from HTF LL/HH = pullback explanation first.
Valid parent KL break = hierarchy invalidation and recalculation trigger.
Parent KL / supply / demand break changes child story.
Child can warn early, but parent valid break officially changes the story.
After parent break, child recalculates from the opposite direction.
```

## Parent-child examples

### 15M bearish parent broken upward

Before break:

```text
15M bearish KL DOWN / supply active
5M mission = explain bearish reaction from 15M KL DOWN / supply
```

Break attempt:

```text
5M moves above 15M KL DOWN
15M break not validated yet
5M mission = transition warning only
```

Validated break:

```text
15M KL DOWN / supply breaks upward with valid NCI pressure
15M enters bullish transition / rebuild mode
5M recalculates bullish structure
Broken 15M KL DOWN becomes retest / HL decision area
```

### 15M bullish parent broken downward

Before break:

```text
15M bullish KL UP / demand active
5M mission = explain bullish reaction from 15M KL UP / demand
```

Validated break:

```text
15M KL UP / demand breaks downward with valid NCI pressure
15M enters bearish transition / rebuild mode
5M recalculates bearish structure
Broken 15M KL UP becomes retest / LH decision area
```
