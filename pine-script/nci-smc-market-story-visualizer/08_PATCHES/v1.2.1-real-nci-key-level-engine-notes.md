# v1.2.1 Real NCI Key Level Engine Foundation Notes

Branch: `nci-story-v1.2.1-real-kl-engine`

## Purpose

v1.2 testing confirmed an important issue: the visualizer compiled and the panel worked, but the key levels were wrong.

The root cause was that previous versions treated recent pivot highs/lows as KLs too easily.

This patch starts replacing the placeholder pivot KL logic with a structure-derived NCI key-level foundation.

## Core correction

```text
Wrong KL = wrong story.
NCI key levels must be structure-derived, not pivot-derived.
```

## What v1.2.1 changes

- Stops labeling raw pivots directly as KL UP / KL DOWN.
- Adds swing validation using impulse distance and ATR.
- Adds direction-aware structure classification.
- Adds separate labels for:
  - candidate pivot,
  - unconfirmed level,
  - confirmed working KL,
  - parent KL,
  - broken-level retest.
- Adds KL source/status into the panel.
- Adds cleaner level naming:
  - Parent KL UP / Parent KL DOWN,
  - Working KL UP / Working KL DOWN,
  - candidate high / candidate low.

## NCI KL interpretation used in this foundation

### Bullish context

```text
KL UP = structurally valid HL / demand-side decision level.
KL DOWN = structurally valid HH / upper objective or breakout decision level.
```

### Bearish context

```text
KL DOWN = structurally valid LH / supply-side decision level.
KL UP = structurally valid LL / lower objective or breakdown decision level.
```

### Mixed / range context

```text
Range high / range low are not automatically KLs.
They are candidate range edges until structure validates them.
```

## Important implementation limitation

This is still foundation logic. It does not yet fully reproduce every NCI course rule.

Future refinements needed:

```text
real breakout standard
real pullback standard
valid range-after-breakout logic
NCI wave path memory
no-base / having-base / long-tail SD precision
obsolete KL / obsolete SD reasons
```

## Correct test expectation

v1.2.1 should be judged only on whether the KLs are less random and more structurally sensible than v1.2.

Do not judge final NCI accuracy yet.
