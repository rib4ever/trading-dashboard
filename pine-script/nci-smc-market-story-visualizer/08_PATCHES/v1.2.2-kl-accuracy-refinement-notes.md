# v1.2.2 NCI KL Accuracy Refinement Notes

Branch: `nci-story-v1.2.2-kl-accuracy-refinement`

## Purpose

v1.2.1 improved visual clarity by stopping raw pivots from being automatically drawn as working KLs. However, Ravi correctly confirmed that the key-level engine still needs deeper NCI accuracy.

v1.2.2 improves the KL foundation by making key levels depend on a connected structure path and market-cycle role instead of only the latest validated swing.

## Core correction

```text
KL is not just a pivot.
KL = validated structure point + active direction + market-cycle role + parent-child context.
```

## What v1.2.2 adds

- Structure path quality classification.
- Market-cycle stage classification:
  - bullish continuation,
  - bearish continuation,
  - bullish pullback candidate,
  - bearish pullback candidate,
  - transition / mixed,
  - range candidate,
  - building.
- Direction-aware KL role assignment.
- Separates:
  - Confirmed Parent KL,
  - Working KL,
  - Candidate edge,
  - Unconfirmed swing.
- Adds safer suppression of KLs when the structure path is weak.
- Adds `KL Role` and `Cycle` rows in the panel.
- Keeps Ultra Clean mode as default.

## Updated KL assignment logic

### Bullish continuation

```text
KL UP = latest valid HL / demand-side decision level.
KL DOWN = latest valid HH / upper decision / breakout objective.
```

### Bearish continuation

```text
KL DOWN = latest valid LH / supply-side decision level.
KL UP = latest valid LL / lower decision / breakdown objective.
```

### Mixed / transition

```text
Do not call levels KL.
Show candidate edge / transition only.
```

### Range candidate

```text
Do not call range edges KL yet.
Label as candidate range high / candidate range low until NCI range logic confirms.
```

## Parent-child hierarchy preserved

```text
4H break → 1H recalculates
1H break → 15M recalculates
15M break → 5M recalculates
```

## Important limitation

This is still not the final NCI course-level KL engine. It is an accuracy refinement layer.

Future refinements still need:

```text
full NCI breakout standard
full NCI pullback standard
range-after-breakout validation
wave memory
proper SD safety-zone drawing
obsolete KL/SD reasons
```

## Testing goal

```text

2. More candidate-only states when structure is unclear.
3. Parent KL appears only when parent structure is confirmed.
4. Working KL appears only when working structure is confirmed.
5. Panel explains cycle/role clearly.
```
