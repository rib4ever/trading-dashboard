# v1.2.2.2 Visibility + Local Context Guard Notes

## Purpose

Ravi tested v1.2.2.1 and confirmed that the logic compiles, but the chart can become visually useless when parent KLs are too far from current price.

Symptoms observed:

```text
far parent KLs stretch the chart scale
working KL may be unavailable because child structure is not confirmed
lower timeframe can look empty/invisible after switching TFs
```

## Fix

v1.2.2.2 adds a visibility guard:

```text
Max Parent KL Distance ATR
Hide far parent KLs by default
Show local candidate context when parent KL is far or working KL is not confirmed
Add panel row: Visible
```

## New behavior

If parent KL is too far:

```text
Panel: Parent clear but far; showing local context
Chart: far parent KL hidden, local edge high/low shown instead
```

If working KL is not confirmed:

```text
Panel: local fallback active
Chart: local candidate edges shown as Local edge, not KL
```
