# v1.2.3 Manual Anchor Calibration Notes

## Purpose

v1.2.3 adds Manual-Anchor Calibration Mode.

Ravi's manual NCI drawings are currently the source of truth. The auto KL engine must be calibrated against those manual anchors before more SMC/SATS logic is added.

## Permanent rule

```text
Manual NCI anchor beats automatic KL until auto engine proves alignment.
```

## Added features

```text
Manual Anchor Calibration toggle
Manual Anchor TF selector: H4 / H1 / M15 / M5
Manual Direction input: Bullish / Bearish / Range / Mixed
Manual KL UP input
Manual KL DOWN input
Manual vs Auto tolerance ATR
Manual Anchor Overrides Auto Story toggle
```

## Panel comparison

The panel now compares:

```text
Manual direction vs Auto direction
Manual KL UP vs Auto KL UP
Manual KL DOWN vs Auto KL DOWN
aligned / auto too high / auto too low / auto missing
```

## Visuals

Manual anchors draw separately from auto KLs:

```text
Manual KL UP = aqua line
Manual KL DOWN = fuchsia line
Auto KLs are hidden by default when manual override is active
Working KL and local fallback can still display
```

## How Ravi should use it

1. Identify the correct manual NCI KL UP / KL DOWN from his chart.
2. Open indicator settings.
3. Enable Manual Anchor Calibration.
4. Enter manual direction and KL values.
5. Check the Compare row.
6. Send screenshots where auto is too high / too low / missing.
