# v1.2.3.1 Manual Input Compile Hotfix Notes

## Purpose

Ravi tested v1.2.3 and found compile errors.

Errors:

```text
The defval parameter of input.float() cannot accept a na argument.
Undeclared identifier showWorkingKL.
```

## Root cause

Pine Script does not allow `input.float(na, ...)` as a default input value.

Also, `showWorkingKL` was used in the visual section but the input was missing from the display settings.

## Fix

v1.2.3.1 replaces manual input defaults with zero-based empty values:

```pine
manualKLUpInput = input.float(0.0, "Manual KL UP - use 0 if empty")
manualKLDownInput = input.float(0.0, "Manual KL DOWN - use 0 if empty")

manualKLUp = manualKLUpInput == 0.0 ? na : manualKLUpInput
manualKLDown = manualKLDownInput == 0.0 ? na : manualKLDownInput
```

Added missing input:

```pine
showWorkingKL = input.bool(true, "Show Working KL")
```

## How to use manual inputs

If you do not want to enter a manual level, leave it as:

```text
0
```

If you want to enter a manual level, type the exact price.

Example:

```text
Manual KL UP - use 0 if empty = 80214.55
Manual KL DOWN - use 0 if empty = 81055.00
```
