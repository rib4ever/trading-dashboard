# v1.2.4 Multi-Anchor Hierarchy Calibration Notes

## Purpose

v1.2.4 expands manual calibration from one anchor pair to a complete hierarchy stack.

Ravi's real workflow is not one HTF/LTF pair. It is:

```text
4H -> 1H -> 15M -> 5M
```

The script now supports calibrating these layers together.

## New manual anchor groups

```text
Manual 4H Master Anchor
Manual 1H Anchor
Manual 15M Anchor
Manual 5M Anchor
```

Each group has:

```text
Enable anchor
Manual Direction
Manual KL UP
Manual KL DOWN
Role / Event
```

## Important story rule encoded

```text
If 4H KL DOWN is touched and pullback is active,
then 1H / 15M / 5M structure should explain the 4H pullback,
not create a completely independent bullish/bearish story.
```

## Panel rows

The panel now shows:

```text
Master
Hierarchy
Confidence
4H Manual
4H Auto
1H Role
15M Role
5M Role
```

Normal and Debug panel modes also show more compare rows.

## Visual layer rules

Manual levels are role-based:

```text
MANUAL 4H KL UP / DOWN
MANUAL 1H KL UP / DOWN
MANUAL 15M KL UP / DOWN
MANUAL 5M KL UP / DOWN
```

Default setting `Show Only Current Relevant Layer` prevents all four layers from overwhelming the chart.
