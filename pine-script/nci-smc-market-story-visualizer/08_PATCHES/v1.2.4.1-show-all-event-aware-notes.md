# v1.2.4.1 Show-All Anchors + Event-Aware Child Story Notes

## Purpose

Ravi tested v1.2.4 and observed two important issues:

```text
1. Not all manually anchored key levels are visible at the same time.
2. The story says direction mismatch even when the lower timeframe is correctly explaining a 4H pullback.
```

## Fix 1 — Show all manual anchors

v1.2.4 had a setting that filtered visible levels by current chart timeframe.

This meant:

```text
On 5M, mostly 5M/15M were visible.
On 1H, mostly 1H/4H were visible.
```

v1.2.4.1 adds:

```text
Show ALL Manual TF Anchors = true by default
```

So 4H, 1H, 15M, and 5M manual anchors can all display together.

## Fix 2 — Event-aware child interpretation

Direction mismatch is not always wrong.

When parent event is:

```text
4H KL DOWN touched / pullback
```

Then:

```text
1H bullish = valid pullback explanation
15M bullish = valid pullback explanation
5M bullish = valid pullback continuation
```

So v1.2.4.1 replaces simple mismatch language with role-aware language.
