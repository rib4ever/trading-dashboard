# v1.2.4.2 Smart Anchor Visibility Notes

## Purpose

Ravi tested v1.2.4.1 and confirmed that all manual anchors can display together, but this creates a new problem:

```text
All TF anchors visible at once can stretch the chart heavily.
The price action becomes too small and difficult to read.
```

This is expected when 4H/H1 anchors are far away while viewing 15M/5M.

## Fix

v1.2.4.2 adds an Anchor View Mode:

```text
Story Focus
Show All Manual Anchors
Current TF Pair Only
```

## Default mode

```text
Story Focus
```

Story Focus keeps all anchors in the panel, but only draws chart lines that are near current price or relevant to the current timeframe.

## New setting

```text
Story Focus Max Anchor Distance ATR
```

This controls how far an anchor can be from current price before it is hidden from the chart.

## Important distinction

```text
Panel = all story information.
Chart = only readable visual information.
```

This means far 4H/H1 anchors can remain part of the story without destroying lower-timeframe readability.
