# v1.3.0 Auto Hierarchy Engine Notes

## Purpose

Ravi correctly challenged the project direction:

```text
Manual calibration is useful for development, but it cannot be the trading workflow.
The script must move forward and automatically identify NCI structure.
```

v1.3.0 is the first build where Auto mode becomes the default.

## Permanent workflow shift

```text
Manual anchors = optional debug / calibration only
Auto hierarchy = default user workflow
```

## What v1.3.0 adds

```text
Automatic 4H / 1H / 15M / 5M structure cycle detection
Automatic KL UP / KL DOWN per timeframe
Automatic parent event detection
Automatic child role interpretation
Automatic hierarchy story panel
Optional manual debug comparison
Story Focus visibility for clean chart reading
```

## Auto hierarchy model

```text
4H = master event
1H = explains 4H
15M = explains 1H
5M = explains 15M
```

## Auto event states

```text
KL DOWN touched / pullback
KL UP touched / pullback
KL DOWN broken / recalculating bullish
KL UP broken / recalculating bearish
Range active
Transition / wait
Continuation / building
```

## Important limitation

v1.3.0 is not the final NCI standard engine.

It is the first automatic hierarchy pass. It still needs refinement for:

```text
NCI breakout standard
NCI pullback standard
range beginning after breakout/pullback
obsolete KL rejection
strongest supply/demand zone detection
child hierarchy recalculation after parent break
```
