# v1.4.1.1 Compile Hotfix Notes

## Ravi error

Ravi tested v1.4.1 and TradingView showed 14 problems.

Main compile errors:

```text
Cannot call f_phTime with argument occ=i. Series int used but simple int expected.
Cannot call f_plVal with argument occ=i. Series int used but simple int expected.
Cannot call f_plTime with argument occ=i. Series int used but simple int expected.
```

There were also consistency warnings from calling some functions inside conditional expressions.

## Cause

Pine Script requires the `occurrence` argument in `ta.valuewhen()` to be a simple int.

The v1.4.1 candidate search used:

```pine
for i = 0 to 7
    v = f_phVal(i)
```

Inside Pine, `i` becomes a series int, so it cannot be used as the occurrence value.

## Fix

v1.4.1.1 removes the loop-based pivot lookup.

It unrolls the calls explicitly:

```pine
ph0 = ta.valuewhen(not na(ph), ph, 0)
ph1 = ta.valuewhen(not na(ph), ph, 1)
...
ph7 = ta.valuewhen(not na(ph), ph, 7)
```

Then it selects the first unmitigated candidate using chained conditions.

## Additional simplification

To reduce warning noise, v1.4.1.1 temporarily uses the simpler two-candle NCI breakout test and removes the big-small breakout helper from this compile hotfix.

The big-small NCI breakout logic will be reintroduced later in a safer way.
