# v1.4.3 BOS Required KL Notes

## Ravi feedback

Ravi confirmed that v1.4.2 is visually drawing well, but one critical NCI rule was missing:

```text
In order to create a key level, the wave that created that key level must make a break of structure.
If it has not broken the last highest high or lowest low, the latest candidate cannot be considered the active key level.
The engine must use/search the previous valid KL instead.
```

## Added project law

```text
A newly created KL must be BOS-created.
Demand KL = pullback low that led to break above previous swing high.
Supply KL = pullback high that led to break below previous swing low.
No BOS = not active KL; search previous BOS-created KL.
```

## New setting

```text
Require BOS to Create KL = true/false
```

Default:

```text
true
```

## Optional BOS close rule

```text
BOS Requires Close Beyond Structure = true/false
```

Default:

```text
false
```

Meaning:

```text
false = wick break can count as BOS
true = candle close must break structure
```

## Added compact label tooltip mode

Child labels can now be short:

```text
1H SUP
1H DEM
15M SUP
15M DEM
5M SUP
5M DEM
```

Full explanation is stored in the label tooltip for desktop/web hover. On mobile, the panel remains the main explanation source.
