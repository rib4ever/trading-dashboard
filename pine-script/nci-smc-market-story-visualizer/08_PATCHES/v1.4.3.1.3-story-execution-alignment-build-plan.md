
## Reason

The old label `5M execution aligns` only meant:

```text
5M bias == 15M bias
```

That is too simple for the NCI story model.

## New rule

Because the project uses hierarchy:

```text
4H = master story
1H = explains 4H
15M = explains 1H
5M = executes 15M
```

If 15M is valid inside the accepted story and 5M continues/aligned with 15M, then 5M is considered aligned with the whole story chain.

## Execution status levels

```text
EXEC WAIT: HTF not clear
EXEC WAIT: 1H conflict
EXEC WAIT: 15M not valid
EXECUTION ALIGNED
5M building
LOCAL REACTION
```

## Logic intent

```text
storyChainValid = HTF story valid + 1H valid + 15M valid
fiveAlignedTo15 = 5M bias equals 15M bias and not neutral

If storyChainValid and fiveAlignedTo15:
    Execution = EXECUTION ALIGNED
```

## Important

This is still not a buy/sell signal. It means execution layer is aligned with the full market story. Entry trigger logic will be a later module.
