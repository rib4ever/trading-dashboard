# v1.4.3.1.6 — Runtime Guard + Relation Refinement Notes

## Status
Planned implementation after Ravi tested v1.4.3.1.5 and found an H4 runtime error.

## Base
Use:

```text
05_PINE/01_VERSIONS/nci_smc_market_story_visualizer_v1_4_3_1_5_fractal_state_foundation.pine
```

Do not rebuild from scratch. This must be a safe patch on top of v1.4.3.1.5.

## Problems identified from screenshots

### 1. H4 runtime error
The indicator compiles but fails at runtime on the 4H chart. Lower timeframes display correctly.

Likely cause is object creation with invalid values on the same chart timeframe as the master TF:

```text
- na left time
- na top/bottom
- top <= bottom
- lifecycle says broken but visual still tries to draw
- label/box object called when values are incomplete
```

### 2. Relation engine too strict
Current relation can show:

```text
1H→15M: conflict
Execution: EXEC WAIT: 15M not valid
```

But in NCI, a child timeframe counter-move can be a valid pullback/reaction inside parent structure. Counter-move should not always equal conflict.

### 3. Panel too large on mobile
Panel covers price action and zones.

### 4. Label overlap
SMC, 1H, 15M, 5M and execution labels still cluster in dense areas.

### 5. Execution wording needs parent context
Current wording such as `EXEC WATCH: inside 5M supply` should become more contextual:

```text
EXEC WATCH: 5M supply inside 4H range
EXEC WATCH: 5M demand inside 4H range
EXEC WATCH: 5M supply; wait rejection/break
EXEC WATCH: 5M demand; wait reaction/break
```

## Required v1.4.3.1.6 changes

### A. Runtime visual guard
Add:

```pine
f_validZone(int leftT, float top, float bottom) => not na(leftT) and not na(top) and not na(bottom) and top > bottom
```

Only call `box.new()` and `label.new()` if the zone is valid.

### B. Safe wrappers
Replace direct box/label calls with safe wrappers:

```pine
f_safeBox(int leftT, float top, float bottom, color col, int tr) =>
    f_validZone(leftT, top, bottom) ? box.new(left=leftT, top=top, right=f_rightTime(futureBars), bottom=bottom, xloc=xloc.bar_time, bgcolor=color.new(col, tr), border_color=color.new(col, 35), extend=extend.right) : na

f_safeLab(bool allow, int off, float y, string s, string tip, color col, bool smallTxt) =>
    allow and not na(y) ? label.new(x=f_rightTime(off), y=y, text=s, tooltip=tip, xloc=xloc.bar_time, style=label.style_label_left, color=color.new(col, 78), textcolor=color.black, size=smallTxt ? size.tiny : size.small) : na
```

### C. Relation refinement
Relation categories should include:

```text
continues parent
valid pullback inside parent
valid reaction inside parent
decision inside parent
internal range
counter-move watch
true conflict
```

A child opposite bias should be valid if it is still inside the parent range/zone and not broken.

### D. Execution wording refinement
Execution statuses should become:

```text
EXEC WAIT: 4H story building
EXEC WAIT: 1H true conflict
EXEC WAIT: 15M true conflict
EXEC WATCH: 5M supply inside 4H range
EXEC WATCH: 5M demand inside 4H range
EXEC RETEST: near 5M zone
EXEC ALIGNED: monitor 5M reaction
```

### E. Visual Density setting
Add setting:

```text
Clean / Balanced / Full / Debug
```

Default: Balanced.

Clean:
- 4H only + execution when active

Balanced:
- 4H + relevant child zones

Full:
- all zones

Debug:
- all zones + pressure/lifecycle data

### F. Panel Detail setting
Add setting:

```text
Compact / Standard / Debug
```

Default: Standard.

Compact rows:

```text
Final
4H Location
4H→1H
1H→15M
15M→5M
Execution
```
