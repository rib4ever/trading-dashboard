# v1.4.5 Zone Life-Cycle + Smart Visual Filtering Notes

## Why this version exists

Ravi identified that lower-timeframe zones such as 5M supply can remain visible even after price has already broken through them and traded back through them again.

That is not a clean active KL anymore.

It should be treated as one of:

```text
broken
mitigated
flip / retest
old reference only
```

not as a clean active SUP/DEM.

## New project law added

```text
A child TF zone that has been broken must not remain displayed as clean SUP/DEM in normal mode.
If it is useful, mark it as FLIP/retest. Otherwise hide it.
```

## Added setting

```text
Zone Life-Cycle Filter = ON
Hide Broken Child Zones = ON
HTF Decision Mode Visual Filter = ON
```

## Zone status codes used internally

```text
0 = active/outside
1 = inside decision
2 = broken/flip
3 = building/none
```

## Supply lifecycle

```text
Supply created by valid BOS + reaction.
If price breaks above supply top + ATR buffer, supply is broken.
Broken supply must not display as clean supply.
If visible in debug/optional mode, label as FLIP.
```

## Demand lifecycle

```text
Demand created by valid BOS + reaction.
If price breaks below demand bottom - ATR buffer, demand is broken.
Broken demand must not display as clean demand.
If visible in debug/optional mode, label as FLIP.
```

## HTF decision visual filter

When price is inside the 4H supply/demand zone:

```text
4H zone remains priority.
1H remains context.
15M is reduced unless current chart needs it.
5M is hidden unless current chart is 5M or lower.
Panel explains 15M/5M roles as text.
```
