# SMC Visual Entry Models

TradingView Pine v6 study indicator for visualizing three Smart Money Concept study models:

1. Liquidity Sweep Reversal
2. Continuation Pullback
3. Range Raid Reversal

Main file:

```text
00_MASTER_COMPILED/smc-visual-entry-model-master-v0.1.pine
```

## How to use

1. Open the Pine file from GitHub.
2. Use the Raw view.
3. Copy the full script into TradingView Pine Editor.
4. Save and add to chart.
5. Test first on replay mode and historical examples.

## Default chart style

Recommended starting point:

- Instrument: XAUUSD
- Execution chart: 5M or 3M
- Bias timeframe: 1H or 4H
- Session focus: London / New York

## Notes

This project is built as an educational chart-analysis tool only. It creates visual study labels, zones, levels, dashboard states, and alertconditions. It does not place orders.
